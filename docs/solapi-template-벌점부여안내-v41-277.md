# SOLAPI 알림톡 템플릿 등록 안내 — 벌점 부여 즉시 안내 (v41-277)

벌점 **사유에 설정된 낱말(기본 `CCTV`)** 이 들어가면, 누적 점수와 무관하게 그 벌점 한 건을
보호자와 학생 본인에게 바로 알림톡으로 보냅니다. (상벌점 관리 › [자동 상점 기준] › 벌점 부여 즉시 안내)

배경: 의무 차시에 오지 않은 날은 데일리 리포트가 나가지 않아, CCTV 모니터링으로 적발한
태도 불량 벌점을 학생이 받았는지 알 수 없었습니다. (직원 건의)

## 승인 전에도 동작합니다

새 템플릿이 승인·설정되기 전에는 이미 승인된 **상벌점 누적 안내** 템플릿
(`SOLAPI_TEMPLATE_ID_POINT_PENALTY`)을 "관리자 발송 · 수시 안내" 변수로 대신 보냅니다.
저장 메시지에 "누적 안내(벌점 부여 안내 템플릿 승인 전이라 대신)"로 표시됩니다.
새 템플릿 환경변수를 넣으면 그때부터 아래 본문으로 나갑니다.

## 1. SOLAPI 템플릿 등록 값

| 항목 | 입력값 |
|---|---|
| 템플릿 이름 | `벌점 부여 안내` |
| 카테고리 | 서비스이용 › 이용안내/공지 (기존 상벌점 누적 안내와 같은 분류) |
| 메시지 유형 | 기본형, 강조 유형 선택 안 함, 버튼 없음, 보안 템플릿 OFF |
| 변수 | `#{학생명}` `#{일자}` `#{벌점}` `#{사유}` `#{순벌점}` `#{누적벌점}` `#{누적상점}` |
| 변수 예시값 | 김민준 / 2026-10-21 / 3 / CCTV 모니터링 중 태도 불량(휴대폰 사용) / 7 / 9 / 2 |
| 환경변수 | `SOLAPI_TEMPLATE_ID_POINT_PENALTY_EVENT` (승인된 템플릿 ID) |

### 본문 (그대로 복사)

```
[BEYOND 학습집중관리센터] 벌점 부여 안내

#{학생명} 학생에게 아래와 같이 벌점이 부여되어 안내드립니다.

- 일자: #{일자}
- 벌점: #{벌점}점
- 사유: #{사유}
- 누적 순벌점: #{순벌점}점 (누적 벌점 #{누적벌점}점 - 누적 상점 #{누적상점}점)

상벌점은 수강 계약에 따라 운영되는 학습관리 프로그램의 운영 규정에 따라 기록됩니다. 가정에서도 생활 지도에 협조 부탁드립니다.

문의: BEYOND 학습집중관리센터 031-795-3306
```

### 심사 참고 메모

- 수강 계약을 맺은 학습관리센터 수강생의 보호자·학생에게, 운영 규정에 따라 기록된 벌점 내역을 통지하는 정보성 메시지입니다. (기존 승인 템플릿 "상벌점 누적 안내"와 같은 성격)
- 수신자는 센터에 연락처를 등록하고 알림 수신에 동의한 보호자·학생입니다. 광고·판촉 내용이 없습니다.
- `#{사유}` 변수는 관리자가 적은 벌점 사유(100자 이내)가 들어갑니다.

## 2. 동작

- 상벌점 관리에서 벌점을 저장할 때 사유에 낱말이 있으면 저장 전에 확인창이 뜨고, 저장과 동시에 발송됩니다.
- 낱말이 없는 벌점은 자동으로 보내지 않습니다. 필요할 때 기록 카드의 [누적 안내 알림톡] 버튼을 누릅니다. (승인된 누적 안내 템플릿, 단계 기준 무관, 여러 번 가능)
- 누적 순벌점은 지금 보고 있는 기수 기간 안의 합계입니다.
- 발송 결과는 저장 메시지에 함께 표시되고, 설정 › 출결 알림 로그에 "벌점 부여 안내" 또는 "벌점 수시 안내"로 남습니다.
- 낱말은 [자동 상점 기준]에서 바꿀 수 있고(최대 10개, 대소문자 무관), 기능을 끌 수도 있습니다.
