# 알림톡 템플릿 등록 안내 — 비욘드 좌석번호 및 닉네임 안내 (v41-271)

매 기수 시작 전에 수강생 보호자에게 좌석번호와 닉네임을 개별로 안내하는 템플릿입니다.
Beyond OS 설정 › 공지사항 발송 › 유형 **[좌석번호·닉네임 안내]** 에서 보냅니다.

## 1. SOLAPI(카카오 비즈니스) 템플릿 등록

- 템플릿 이름: `비욘드 좌석번호 및 닉네임 안내`
- 메시지 유형: 기본형 (버튼 없음)
- 카테고리: 교육 › 수강/학사 안내 (정보성)
- 변수 3개: `#{학생이름}` `#{좌석번호}` `#{닉네임}`
- 강조 표기(말머리)를 쓰실 경우: 강조 유형 "강조표기형", 강조 문구 `비욘드 좌석번호 및 닉네임 안내`
- 본문 글자 수 약 520자 (한도 1,000자)

### 본문 (그대로 복사)

```

[개별 안내]

타인에게 공개하지 마시고 본인 닉네임을 꼭 기억해 주세요.

[태블릿 준비 안내]

비욘드 학기 중 프로그램에서도 차단앱을 통해 비학습 앱 사용을 자체적으로 제한할 예정입니다.
다만 기술적인 차단만으로는 한계가 있습니다.
결국 학습 환경을 지키는 가장 확실한 방법은 학생 본인의 자발적인 실천입니다.
가정에서도 함께 점검해 주시면 아이가 훨씬 수월하게 집중할 수 있습니다.

감사합니다.

문의: The Place 26 비욘드 학습관리센터 (031-795-3306)
```

### 변수에 들어가는 값 (Beyond OS가 자동으로 채움)

| 변수 | 값 | 예시 |
|---|---|---|
| `#{학생이름}` | 학생 정보의 이름 | 김민준 |
| `#{좌석번호}` | 학생 정보의 기본 좌석 + "번" | 26번 |
| `#{닉네임}` | 학생 정보의 닉네임. 랭킹 공개 미동의이고 닉네임이 없으면 "비공개 (랭킹에 ♥♥♥로 표기)" | 야무짐 |

### 심사 참고 메모 (카카오 템플릿 심사 코멘트에 적을 내용)

- 수강 계약을 맺은 학습관리센터 수강생 보호자에게, 수강 시작 전 배정된 좌석번호와 랭킹 표시용 닉네임을 개별 통지하는 정보성 메시지입니다.
- 수신자는 센터에 자녀 정보와 연락처를 등록하고 알림 수신에 동의한 보호자입니다.
- 광고·판촉 내용이 없습니다.

## 2. 승인 후 Vercel 환경변수

| 이름 | 값 |
|---|---|
| `SOLAPI_TEMPLATE_ID_NOTICE_SEAT_NICKNAME` | 승인된 템플릿 ID |

환경변수를 넣고 재배포하면 공지사항 발송에서 이 유형이 실제로 나갑니다. 넣기 전에는 "SOLAPI 설정이 부족합니다" 로 멈춥니다.

## 3. 발송 전 점검 (Beyond OS)

1. 화면 상단 [기수 보기]에서 보낼 기수를 고릅니다. 그 기수 수강 명단에만 나갑니다.
2. 설정 › 학생 관리에서 수강생의 **기본 좌석**과 **닉네임**이 채워져 있는지 확인합니다. 닉네임은 [닉네임 일괄 배정]으로 한 번에 만들 수 있습니다.
3. 설정 › 공지사항 발송 › [좌석번호·닉네임 안내] 유형 → 제목(내부용, 예: "3기 좌석·닉네임 안내") 입력 → [공지 저장] → [발송 준비].
4. 확인창에 보낼 학생(좌석·닉네임)과 빠지는 학생(사유)이 나옵니다. 빠지는 학생은 정보를 채운 뒤 다시 [발송 준비]를 누르면 들어옵니다.
5. 테스트 수신번호 모드에서는 첫 학생의 값이 견본으로 테스트 번호에 갑니다. 실전 발송 전에 설정 › 리포트 발송 설정에서 테스트 모드를 끕니다.

## 4. 동작 규칙

- 보호자 기준: 활성 학생 · 데일리 리포트 수신 ON 보호자. 수신 대상을 [학생]/[둘 다]로 바꾸면 학생 본인 연락처에도 갑니다.
- 형제가 같은 기수에 있으면 보호자 한 번호로 학생 수만큼 각각 나갑니다. (내용이 다르므로 중복 허용)
- 보호자 번호와 학생 번호가 같으면 그 학생 건은 한 통만 갑니다.
- 발송 이력은 공지 목록의 [발송 대상]에서 "학생 · 보호자 · 번호(마스킹)" 로 남습니다.
