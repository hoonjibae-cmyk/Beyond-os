# SOLAPI 알림톡 템플릿 등록 안내 — 상벌점 (v41-161)

상벌점 관리 화면의 **[학부모 알림 완료]** / **[상품지급안내완료]** 버튼이 실제로 알림톡을
보내도록 바뀌었습니다. 아래 두 템플릿을 카카오 비즈니스 채널에 등록·승인받아야 발송됩니다.

승인 전까지는 버튼을 눌러도 기록만 남고, 화면에 `SOLAPI 설정이 부족합니다` 또는
템플릿 오류 메시지가 함께 표시됩니다. (조치 기록 자체는 정상 저장됩니다)

---

## 1. 상벌점 누적 안내 (벌점 단계)

- **템플릿 용도**: 순벌점이 10 / 20 / 30점을 초과해 조치할 때 보호자·학생에게 발송
- **메시지 유형**: 기본형 (채널 추가 유도 없음)
- **강조 표기**: 없음
- **환경변수 이름**: `SOLAPI_TEMPLATE_ID_POINT_PENALTY`

### 템플릿 본문 (그대로 등록)

```
[BEYOND 학습집중관리센터] 상벌점 누적 안내

#{학생명} 학생 상벌점 누적 현황을 안내드립니다.

- 기준일: #{기준일}
- 누적 상점: #{상점}점
- 누적 벌점: #{벌점}점
- 순벌점: #{순벌점}점 (#{안내단계})

#{안내문구}

최근 상벌점 내역
#{최근내역}

문의: BEYOND 학습집중관리센터 031-795-3306
```

### 변수 목록 (8개)

| 변수 | 예시 값 |
| --- | --- |
| `#{학생명}` | 박시은 |
| `#{기준일}` | 2026-08-14 |
| `#{상점}` | 8 |
| `#{벌점}` | 22 |
| `#{순벌점}` | 14 |
| `#{안내단계}` | 10점 초과 · 학부모 알림 |
| `#{안내문구}` | 누적 벌점이 기준을 초과하여 안내드립니다. 가정에서도 생활 지도에 협조 부탁드립니다. |
| `#{최근내역}` | 2026-08-11 상점 +2점 (모범 태도)<br>2026-08-11 벌점 -2점 (지각) … (최대 5줄) |

### `#{안내문구}`에 들어가는 단계별 문장

| 단계 | 문장 |
| --- | --- |
| 10점 초과 | 누적 벌점이 기준을 초과하여 안내드립니다. 가정에서도 생활 지도에 협조 부탁드립니다. |
| 20점 초과 | 누적 벌점이 기준을 초과하여 센터장 면담이 필요합니다. 센터로 연락 주시면 일정을 안내드리겠습니다. |
| 30점 초과 | 누적 벌점이 기준을 크게 초과하여 계속 수강 여부를 함께 논의드려야 합니다. 센터로 연락 부탁드립니다. |

> 30점(제적) 단계는 알림톡으로 제적을 통보하지 않고 **상담 요청**으로 표현했습니다.
> 문서 한 줄로 끝낼 사안이 아니고, 통보성 문구는 템플릿 심사에서도 반려되기 쉽습니다.
> 문구를 바꾸시려면 `lib/pointNotifications.js`의 `PENALTY_STAGE_MESSAGES`를 수정하세요.

## 2. 상점 누적 상품 지급 안내

- **템플릿 용도**: 순점수가 기준(10점)을 초과해 상품을 지급할 때 보호자·학생에게 발송
- **메시지 유형**: 기본형
- **환경변수 이름**: `SOLAPI_TEMPLATE_ID_POINT_REWARD`

### 템플릿 본문 (그대로 등록)

```
[BEYOND 학습집중관리센터] 상점 누적 상품 지급 안내

#{학생명} 학생이 상점 누적 기준을 달성했습니다.

- 기준일: #{기준일}
- 누적 상점: #{상점}점
- 누적 벌점: #{벌점}점
- 순점수: #{순점수}점

#{지급안내}

최근 상벌점 내역
#{최근내역}

문의: BEYOND 학습집중관리센터 031-795-3306
```

### 변수 목록 (7개)

| 변수 | 예시 값 |
| --- | --- |
| `#{학생명}` | 문혜주 |
| `#{기준일}` | 2026-08-14 |
| `#{상점}` | 22 |
| `#{벌점}` | 0 |
| `#{순점수}` | 22 |
| `#{지급안내}` | 센터에서 상품 지급 안내를 드릴 예정입니다. 앞으로도 좋은 습관 이어가도록 함께 응원해 주세요. |
| `#{최근내역}` | 2026-08-10 상점 +5점 (주간개근) … (최대 5줄) |

## 3. 등록 후 Vercel 환경변수 설정

승인이 나면 템플릿 ID를 Vercel 환경변수에 넣어야 발송됩니다.

```
SOLAPI_TEMPLATE_ID_POINT_PENALTY = <벌점 안내 템플릿 ID>
SOLAPI_TEMPLATE_ID_POINT_REWARD  = <상품 지급 안내 템플릿 ID>
```

기존 `SOLAPI_API_KEY` / `SOLAPI_API_SECRET` / `SOLAPI_CHANNEL_ID`는 그대로 씁니다.

---

## 4. 발송 대상

두 알림 모두 **보호자 전원 + 학생 본인**에게 함께 나갑니다.

- 보호자: 학생 정보에 등록된 활성 보호자 연락처 (없으면 대표 보호자 번호)
- 학생: 학생 연락처가 등록되어 있을 때만
- 보호자와 학생 번호가 같으면 한 번만 보냅니다

데일리·위클리 리포트의 "학생 본인에게도 발송" 설정과는 별개입니다.
상벌점은 학생이 직접 알아야 행동이 바뀌는 정보라 기본 포함했습니다.

## 5. 발송되지 않는 경우

| 버튼 | 발송 |
| --- | --- |
| 벌점 단계 **[조치 완료]** | 발송 |
| 벌점 단계 **[보류]** | 발송 안 함 |
| **[상품지급안내완료]** | 발송 |
| **[미지급]** | 발송 안 함 |

발송에 실패해도 조치·지급 기록은 그대로 남습니다. 화면 메시지에 실패 사유가 함께 표시되며,
발송 이력은 `attendance_notification_logs` 테이블에 `event_type = point_penalty / point_reward`로
쌓입니다.
